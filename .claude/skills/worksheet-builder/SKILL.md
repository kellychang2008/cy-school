# 英語學習單與測驗卷

## 步驟
1. 確認程度、主題或文法點、題數、時間、是否要配分。
2. 依程度選題型:單字配對、選擇、填空、改錯、重組句子、閱讀理解、短文寫作。
3. 題目由易到難排列,每個文法點至少 2 題。
4. 閱讀文章的長度與字彙需符合程度,生難字附註。
5. 附完整答案與簡短解析;選擇題的錯誤選項要有誘答力。

## 輸出
- 第一部分:學生版(不含答案)
- 第二部分:教師版(答案、配分、解析、常見錯誤)

出完後自行檢查英文拼字與文法,確認每題只有一個正確答案。繁體中文指示、英文題目。
