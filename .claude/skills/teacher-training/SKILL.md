# 教師培訓規劃

## 步驟
1. 確認對象(新進、資深、兼職)、人數、總時數、要解決的教學問題。
2. 訂定 2 到 4 個培訓目標,寫成可檢核的行為。
3. 設計時間表:講解 → 示範 → 演練 → 回饋 → 反思,講解不超過三分之一。
4. 製作配套:
   - 教學觀察表(班級經營、語言使用、互動、目標達成)
   - 回饋範本:優點、具體建議、下一步
   - 培訓後追蹤計畫(1 週、1 個月)

## 輸出格式
培訓名稱、目標、時間表(時間 / 內容 / 方法 / 材料)、觀察表、追蹤計畫。

繁體中文,內容要能直接用於班內培訓。
