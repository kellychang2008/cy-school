一首歌學英文：Keep Going (One Step More)
命令句、be 動詞否定、If 條件句

簡誼 Song for Study 系列

Keep Going 是一首給「想放棄的那一刻」的歌，句子短、節奏穩，很適合用來練 If 條件句。這首 Keep Going (One Step More) 難度約為 CEFR A2（可延伸到 A2+），適合已經有基礎、想把句型說得更自然的學習者。

▶Keep Going (One Step More)在 YouTube 觀看歌曲影片

這首歌學到的 5 個文法重點

1. 祈使句Breathe in slow. / Keep going.
2. be 動詞否定You're not late. You're not done yet.
3. canYou can do it!
4. If 條件句If you fall, fall forward. / If you doubt, call someone. / If you stop, start again.
5. 感官動詞 + 原形Watch that zipper catch the sun.

怎麼用這首歌學？

  1. 先完整聽一遍，不看歌詞，感受節奏與情緒。
  2. 再聽一遍，用學習單把聽到的單字寫下來。
  3. 找出上述 5 個句型，各挑一句大聲唱出來。
  4. 仿寫一句：今天你的 Keep Going 是什麼？用英文寫一句：If you ______, ______.
